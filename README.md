# Gift Track Bot

Бот уведомляет о только что улучшенных Telegram-подарках (NFT) по фильтрам пользователя,
даёт ссылку на владельца и создаёт закрытый чат для сделки. Подписка - за Telegram Stars.
Один процесс: aiogram (бот) + Telethon (мониторинг) + aiohttp (Mini App и API).

## Запуск
1. **my.telegram.org** -> API development tools -> получи `API_ID`, `API_HASH`.
2. **@BotFather** -> `/newbot` -> `BOT_TOKEN`.
3. Локально: `pip install telethon && python generate_session.py` -> `SESSION_STRING`
   (используй ОТДЕЛЬНЫЙ аккаунт, не основной).
4. Залей папку в GitHub-репозиторий.
5. **Railway**: New Project -> Deploy from GitHub repo -> выбери репозиторий.
6. В проекте: New -> Database -> PostgreSQL.
7. В сервисе бота -> Variables: добавь переменные из `.env.example`
   (`DATABASE_URL` = `${{Postgres.DATABASE_URL}}`).
8. Settings -> Networking -> Generate Domain, вставь домен в `WEBAPP_URL`, Redeploy.
9. @BotFather -> `/mybots` -> твой бот -> Bot Settings -> Menu Button -> укажи `WEBAPP_URL`.
10. Напиши боту `/start` (админы из `ADMIN_IDS` имеют доступ сразу). Друзьям: они жмут `/start`, ты пишешь `/allow <их_id>`.

## Команды
`/start` (список функций), `/status`, админ: `/allow <user_id>`, `/deny <user_id>`, `/grant <user_id> <дней>` (только при `PAID_MODE=1`)

## Важно
- Схема TL по подаркам меняется: если после обновления Telethon что-то упало,
  проверь `core.telegram.org/schema` (методы `payments.getUniqueStarGift`,
  `payments.getStarGifts`, `payments.getResaleStarGifts`).
- Чтобы Telegram не сбрасывал сессию, запросы ограничены (`RPS`) и идут адаптивно: коллекции, где недавно
  были улучшения, проверяются каждые `MIN_INTERVAL` сек, остальные реже, до `MAX_INTERVAL`.
  Чем уже `COLLECTIONS`, тем быстрее реакция. Не используй один `SESSION_STRING` в двух местах одновременно.
- Цена в уведомлении - ориентир (флор коллекции на маркете), не оценка конкретной редкости.
- Бот не пишет владельцам сам: покупатель нажимает кнопку, открывается чат с готовым текстом (черновик), отправляет он сам.

## Поиск и оценка
- Для подарка, который кому-то подходит, бот запрашивает маркет Telegram: флор коллекции, модели, фона и пары
  модель+фон (с числом листингов). Это 3 доп. запроса на подарок, результаты кэшируются на 10 минут.
- Режим выгодных предложений: редкий признак, ИЛИ модель/фон дороже флора коллекции в `PREMIUM_X` раз
  (флор считается, если листингов не меньше `MIN_LISTED`), ИЛИ красивый номер.
- Фильтры-исключения: коллекции, модели, фоны, которые не нужно показывать.

## Офферы
- У подарка есть поле `offer_min_stars`: если оно задано, на подарок можно отправить оффер (встроенная покупка Telegram с защитой сделки).
  Поле приходит вместе с подарком, лишних запросов нет. Владелец у такого подарка всегда известен.
- `ONLY_OFFERABLE=1` (по умолчанию): бот присылает только такие подарки и показывает минимальный оффер (⭐ и ≈GRAM).
  Оффер делаешь сам: открой подарок кнопкой «Открыть подарок» и предложи цену в карточке.
- Если установленный Telethon не знает это поле, в логе будет предупреждение, а фильтр отключится (иначе бот молчал бы совсем).
  Лечится обновлением: `pip install -U telethon`, передеплоем.
- `ONLY_REACHABLE=1` (по умолчанию) работает вместе с `ONLY_OFFERABLE`: подарок должен пройти оба фильтра - оффер возможен и владельцу можно написать.

## Кому можно написать
- Профиль владельца приходит вместе с подарком (бесплатно, без лишних запросов). Если его нет, бот один раз дозапрашивает профиль,
  но только для подарка, который кому-то подошёл по фильтрам.
- `ONLY_REACHABLE=1` (по умолчанию): подарок без владельца-пользователя (кошелёк, скрыт), без username, с удалённым аккаунтом
  или с ботом пропускается, уведомления нет. В логе: `<slug> пропущен: <причина>`.
- Если у владельца включено «писать только Premium» или платные сообщения - пропускается тоже (`ALLOW_RESTRICTED=1` отключает эту проверку).
  Проверка по флагам профиля, которые отдаёт Telegram. Полностью закрытые от всех ЛС заранее не видно.
- Кнопка «Написать владельцу» = `https://t.me/<username>?text=...`, текст берётся из `MSG_TEMPLATE`
  (поля `{collection}`, `{num}`, `{link}`). Если на каком-то клиенте текст не подставился, чат всё равно откроется.

## Portals
- Публичный API Portals, без авторизации и без юзербота. В уведомлении блок «Portals»: флор коллекции, модели, фона и пары (GRAM).
- Курс GRAM/⭐ берётся из листингов Telegram (в них цена сразу в обеих валютах), внешних сервисов не нужно.
- В режиме выгодных: если подарок уже в листинге Telegram и дешевле Portals на `PORTALS_DISCOUNT`% - это причина показать.
- Если Portals отвечает 403/429/ошибкой, он отключается на несколько минут, а уведомления идут как обычно.
- Формат ответов Portals неофициальный. Проверка вживую: `python check_markets.py "Plush Pepe" "<модель>" "<фон>"`.
