# Gift Track Bot

Бот уведомляет о только что улучшенных Telegram-подарках (NFT) по фильтрам пользователя,
даёт ссылку на владельца и создаёт закрытый чат для сделки. Подписка - за Telegram Stars.
Один процесс: aiogram (бот) + Telethon (мониторинг) + aiohttp (Mini App и API).

## Запуск
1. **my.telegram.org** -> API development tools -> получи `API_ID`, `API_HASH`.
2. **@BotFather** -> `/newbot` -> `BOT_TOKEN`.
3. Локально: `pip install telethon && python generate_session.py` -> `SESSION_STRING`
   (используй ОТДЕЛЬНЫЙ аккаунт, не основной).
4. Залей папку в GitHub-репозиторий.
5. **Railway**: New Project -> Deploy from GitHub repo -> выбери репозиторий.
6. В проекте: New -> Database -> PostgreSQL.
7. В сервисе бота -> Variables: добавь переменные из `.env.example`
   (`DATABASE_URL` = `${{Postgres.DATABASE_URL}}`).
8. Settings -> Networking -> Generate Domain, вставь домен в `WEBAPP_URL`, Redeploy.
9. @BotFather -> `/mybots` -> твой бот -> Bot Settings -> Menu Button -> укажи `WEBAPP_URL`.
10. Напиши боту `/start` (админы из `ADMIN_IDS` имеют доступ сразу). Друзьям: они жмут `/start`, ты пишешь `/allow <их_id>`.

## Команды
`/start` (список функций), `/status`, админ: `/users` (список людей), `/health` (состояние), `/allow <user_id>`, `/deny <user_id>`, `/grant <user_id> <дней>` (только при `PAID_MODE=1`)

## Важно
- Схема TL по подаркам меняется: если после обновления Telethon что-то упало,
  проверь `core.telegram.org/schema` (методы `payments.getUniqueStarGift`,
  `payments.getStarGifts`, `payments.getResaleStarGifts`).
- Чтобы Telegram не сбрасывал сессию, запросы ограничены (`RPS`) и идут адаптивно: коллекции, где недавно
  были улучшения, проверяются каждые `MIN_INTERVAL` сек, остальные реже, до `MAX_INTERVAL`.
  Чем уже `COLLECTIONS`, тем быстрее реакция. Не используй один `SESSION_STRING` в двух местах одновременно.
- Цена в уведомлении - ориентир (флор коллекции на маркете), не оценка конкретной редкости.
- Бот не пишет владельцам сам: покупатель нажимает кнопку и пишет лично.

## Поиск и оценка
- Для подарка, который кому-то подходит, бот запрашивает маркет Telegram: флор коллекции, модели, фона и пары
  модель+фон (с числом листингов). Это 3 доп. запроса на подарок, результаты кэшируются на 10 минут.
- Режим выгодных предложений: редкий признак, ИЛИ модель/фон дороже флора коллекции в `PREMIUM_X` раз
  (флор считается, если листингов не меньше `MIN_LISTED`), ИЛИ красивый номер.
- Фильтры-исключения: коллекции, модели, фоны, которые не нужно показывать.

## Контроль состояния
Админы (`ADMIN_IDS`) получают сообщения: запуск мониторинга, нет ответов Telegram дольше `STALL_SECONDS`
(и когда связь вернулась), большой FloodWait, сброс сессии, падение бота, нет новых подарков дольше
`NO_GIFTS_HOURS`. Одинаковые алерты не чаще раза в 30 минут (а при перезапусках в цикле - тем более).

## Меню
При запуске бот сам выставляет список команд и кнопку меню с приложением (по `WEBAPP_URL`),
настраивать их в BotFather больше не нужно. Админам в списке команд показываются и админские.

## Меню
- Постоянные кнопки внизу чата (после `/start`): Начать/Завершить работу, Выгода вкл/выкл, Избранное, Статус, Приложение.
- Меню команд по `/`: админам показывается расширенный набор (выставляется при запуске).
- Под уведомлением кнопки «🚫 Коллекция» и «🚫 Модель» добавляют её в исключения (совпадение по части названия).
- Приложение: вкладки Главная / Фильтры / Избранное и быстрые настройки.

## Какие подарки приходят
По умолчанию только те, где (1) владелец - обычный пользователь, которому можно написать (не скрыт, не канал,
не кошелёк TON) и (2) Telegram разрешает отправить Offer to Buy (у подарка задан `offer_min_stars`).
Остальные отбрасываются до запросов к маркету. Отключить условия: `ONLY_CONTACTABLE=0`, `REQUIRE_OFFER=0`.
Нужен `telethon>=1.45.0` (схема со слоем 220+); при старой версии фильтр по офферам отключается сам.

## Сообщения владельцам от аккаунта
Под уведомлением кнопка «✉️ Написать»: выбираешь шаблон (или свой текст), сообщение уходит с аккаунта юзербота.
Ответ владельца приходит в бота с кнопкой «↩️ Ответить». Авто-рассылки нет - только по нажатию.
Защита аккаунта: пауза `RELAY_MIN_GAP`, лимиты `RELAY_DAILY_LIMIT` и `RELAY_GLOBAL_DAILY`, повторно первым
сообщением владельцу не пишем 72 часа, при спам-лимите Telegram отправка встаёт на паузу и админы получают сообщение.
Пересылаются только ответы тех, кому писали. Отключить: `RELAY=0`.

## Авто-режим сообщений
Выключен по умолчанию и доступен только админам и тем, кому админ выдал `/autoallow <id>` (закрыть: `/autodeny <id>`).
Человек запускает режим кнопкой «🤖 Авто» в чате или во вкладке «Авто» приложения: бот сам пишет владельцам подарков,
которые подошли под его фильтры, пока не наберёт лимит (до `AUTO_MAX`=5 за запуск), с паузой между сообщениями
(`AUTO_MIN_GAP`..`AUTO_MAX_GAP`). Потом режим сам выключается. Действуют те же защиты, что у ручных сообщений.
Настройки (лимит, пауза, текст) - во вкладке «Авто». Режим можно поставить на паузу, продолжить или остановить.

## Статистика для админов
`/stats` (или кнопка «📈 Статистика»): подарки, уведомления, сообщения (ручные/авто), ответы владельцев, диалоги,
по каждому человеку за 24 ч и 7 дней. `/stats <id>`: подробно по человеку и его последние диалоги.
